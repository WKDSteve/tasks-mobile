# Learning paths on the phone

The mobile page is a view of the PC's hub; learning paths are **created on the PC**, as files, with the engine (tasks.nvim).
The workflow with all checklists is one document for every surface:

**[tasks.nvim/docs/LEARNING-PATH-WORKFLOW.md](https://github.com/WKDSteve/tasks.nvim/blob/main/docs/LEARNING-PATH-WORKFLOW.md)**

Notes for the phone:

- Write exercise points so they can be done from a small screen: one action, a written-out task in the point's quote, and a
  "Fertig, wenn" line. A point that is only a title ("Üben: `ls -l`") cannot be done on the phone either
  (`tasks.nvim/uebungspunkte-mit-ausformulierter-aufgabe`).
- Keep labels short and on one line; long text belongs in the quote below the point or in a promoted task.
- Images only as assets of the path's folder (`LP-16`).
- What the mobile page shows of learning paths is **not yet documented** here: check it once on a device and write it into
  [USAGE.md](USAGE.md) (open point in the feedback catalog `tasks-vault/tasks.nvim/ROADMAP/reports/2026-11-23_lernplan-anlegen-feedback-katalog.md`).
